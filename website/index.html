A studio, not a toy

Six systems, one workspace — sandboxed, audited and test-covered.

AI Creator + Nexus Agent

Streaming chat with OpenAI-compatible, Anthropic or local Ollama models. The agent edits real project files with 12 sandboxed tools, a hard budget and a full audit trail — destructive actions always ask first.

Real build system

./gradlew build runs for real with a live terminal, an Error Center and Auto-Fix — the agent reads javac errors and patches the code, up to five attempts per build.

Launcher, verified

Isolated instances per project. The official Mojang runtime is downloaded, SHA-1 checked, and your compiled jar lands in mods/ before the game opens with it.

Server Studio

Vanilla or Paper servers from official sources, live console over stdin, world-safe stop, timestamped backups with zip-slip guards — plus free public tunnels via playit.gg.

Shader Studio

32 iconic looks as style presets — BSL, SEUS, Complementary Reimagined and more — generated as 100% original, Iris/OptiFire-compatible shaderpacks with live WebGL preview.

Token Chain

An in-game economy backed by a real SHA-256 hash chain — tamper-evident, mint/burn/transfer, verified with one click. No crypto, no wallets: pure game currency.

The workspace

A dark, focused studio — Monaco editor, live terminals and honest status everywhere.
